# Research working language

Effective 20260930T115754Z, all newly authored communication among Opus, Astra and GPT-5.5 uses English. This includes scientific reports, reviews, execution plans, handoff requests, code comments, experiment descriptions and research-log additions.

Historical Chinese material remains unchanged and is treated as primary evidence. Literal identifiers and necessary source quotations are preserved, with English interpretation. Signed native model blocks, raw results, frozen protocols and evidence hashes are not translated. A resumed session receives the current English policy at the next model call.

The shared working_language.py module applies the policy to current system instructions and preserves tool-call/result records and native signed messages. Model selection, effort, scientific authority, budgets and test boundaries are unchanged. Progress explanations to the human user and the separate final Chinese summary remain in Chinese.

English does not eliminate ambiguity: conclusions must retain explicit definitions, equations, units, thresholds, primary-evidence references and distinct verified findings/hypotheses.
