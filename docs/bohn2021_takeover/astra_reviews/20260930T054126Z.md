### 任务 1——立即推进：`A6` / `A11` / `A13`，terminal × H 因果拆分

4. `v19_c13`

**冻结干预：**

- H = `[12,15,25,35]`
- terminal = `[zero,V15,V35]`
- 每格一次 continuation：**72 episodes，最多 10,800 control steps**
- `zero` 使用同形状零 weights/biases；
- 不改变 reward、discount、constraints、forecast/noise、solver recovery；
- gradient updates、selector 搜索、validation64、sealed test 均为零；
- state 内随机 arm 顺序，冻结随机 seed；
- 不按结果替换状态或补跑“更好”的初始化。

**本轮对辅助求解的细化：** 若尚未冻结/启动，将原有 **24 次不推进 plant 的 solver-call 预算**分配为：

- 两个 context：source242 slot0 起点；c13 的 H15 trace 第 2 行 `previous_state`，对应原 episode step46；
- H = `[12,15,35]`；
- V = `[V15,V35]`；
- 两种 initial guess：canonical 与一个预登记、无搜索的 goal-facing generator。

即 `2×3×2×2=24` 次。两种 guess 必须使用完全相同的状态、TVP、previous input 和参数。**如果已有活动冻结方案，先让其正常完成，不中途改表。**

**必须输出：**

- 每步 stage/slack/terminal/regularization 分解及其重构误差；
- `γ^H V`、terminal state、goal 参数；
- terminal 系数、变量顺序、梯度与曲率诊断；
- 首次动作/轨迹明显分化的位置；

**分流规则：**

- 同 H 仅换 V 就救援或消除成本异常：优先 terminal contract/refit 路线；
- H35 的救援在三种 V 下都保留而短 H 均失败：增强 horizon/geometry 解释；
- 相同 H/V/context 下 alternate guess 给出更低目标并改变关键动作：优先处理 basin/initialization；
- 仅出现负 terminal 常数、不改变梯度或动作：**不据此宣布 terminal bug**；
- reset/forecast/权重契约失败：记工程失败，保留失败格，不替换样本。

**执行前合并处理 `A12`：** 修复新 runner 的 receipt 写入顺序；为旧 v29/v32 新增最终哈希 receipt，不覆盖旧证据。冻结一次备份清单后推进，不为每份重复门检文字重新打开同一门。

### 任务 2——任务 1 后有条件推进：`A7` / `A8` / `A6`，前瞻性新 source 机制确认

**假设：** radius 规律能跨 source 迁移，且在拆清 terminal 后仍存在固定配置之间的真实互补性。
