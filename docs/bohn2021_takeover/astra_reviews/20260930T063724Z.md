### 2. 高：V35 的 heading 非周期性已量化，负曲率构成新的机制线索  
**关联：`A11`**

同一 source242 slot0，固定其他输入、使用 `zero_goal`：

| heading 输入 | V35 |
|---|---:|
| `theta=-4.2121837722681725` | `-173.5207565153844` |
| `theta+2π` | `-149.3826269381251` |
| `theta−2π` | `-372.48232611108534` |

证据：`C33/raw.json:1775–1855`。

全六状态的最大 wrap 差：

- V15：`14.88547931265683`
- V35：`198.96156959570095`

证据：`C33/raw.json:2219–2228`。这里的每个 terminal `samples=24` 是重复函数检查，**不是24个独立场景**。

对于代码所实现的 quadratic polynomial：

\[
V(\theta+h)+V(\theta-h)-2V(\theta)=2q_\theta h^2 .
\]

V35 在上述点的两侧增量之和为负；c13 的对应两侧增量同样为负：  
`−105.53976957189792` 与 `−69.28367044654368`。  
证据：`C33/raw.json:1297–1351`。

因此，**被检查的导出函数在 heading 方向确有负二次系数**。这不是仅由 bias 导致的负 value。

作者表示本身也没有周期性处理：

- TF `poly`：原始输入及逐维平方，`S/stable-baselines-horizon/stable_baselines/sac/policies.py:340–361`；
- CasADi `poly`：同样结构，`S/gym-horizon/gym_let_mpc/utils.py:163–199`。

但必须保留三个界限：

1. **非周期与负曲率不等于已经证明 v33 的因果责任。**
2. 这里是 branch-state value，不是已保存的预测 terminal-state value；后者尚缺。
3. 固定有限 H、有限输入约束下，不能据此宣称 NLP “无界”。

当前更具体的竞争假设是：

> V35 的 heading/position 形状可能对预测轨迹施加非物理偏好；这种偏好可能在部分场景中帮助逃离停滞 basin，在其他场景中损害 tracking。两种效应可以同时存在。

#### 一个应避免继续放大的混杂

对于已看到的无交叉项 polynomial，

\[
V(s,g)=b+\sum_i(a_i z_i+q_i z_i^2),
\]

在固定 H、固定 goal 的一次优化中，**goal-only 项只是对决策变量的常数**。它不能直接改变精确数学意义上的候选轨迹排序。

所以，缺少历史 goal 数值需要补齐以核对映射和总 objective，但不应把“goal 数值尚未恢复”自动视为控制动作差异的首要解释，更不应因此陷入无限 metadata 门检。参数错序、非预期表示或实际部署代码差异则另当别论，仍需真实链路测试。

- 修复部署／映射；
