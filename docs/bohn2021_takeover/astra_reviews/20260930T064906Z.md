### 3. 高：terminal 表示存在可验证的结构限制，但其控制因果责任仍待 probe  
**关联：`A11`、`A6_strong_fixed_H_and_terminal_opportunity_not_closed`**

作者 TF 与 CasADi 的 `poly` 都是：

\[
V(s,g)=b+\sum_i a_i z_i+\sum_i q_i z_i^2,\qquad z=[s,g]
\]

没有交叉项：

- `S/stable-baselines-horizon/stable_baselines/sac/policies.py:340–373`
- `S/gym-horizon/gym_let_mpc/utils.py:163–203`

由此有两项重要推论。

#### 3.1 固定 context 下，goal-only 项不能改变候选轨迹的数学排序

\[
V(s,g)=V_s(s)+C(g),\qquad
\nabla_s V(s,g)=\nabla_s V_s(s)
\]

因此，固定 H、固定 goal 时，goal-only 项只是常数。缺少历史 goal 数值需要注明，但**不能单独当作动作差异的首要解释，也不应成为无限重复门检的理由**。

更深的表示限制是：这个函数族不能一般性表达 goal-relative 二次项中的 state–goal 交互。重新训练同一表示，并不自动消除这种限制。

#### 3.2 V35 的非周期性和 heading 负曲率再次得到相同数值支持

source242 slot0、`zero_goal`：

| heading | V35 |
|---|---:|
| `−4.2121837722681725` | `−173.5207565153844` |
| `theta+2π` | `−149.3826269381251` |
| `theta−2π` | `−372.48232611108534` |

证据：`C49/raw.json:1773–1855`。

两侧差值之和为负，在上述 quadratic 表示下证明 heading 二次系数为负。最大 wrap 差仍为 V15 `14.8854793`、V35 `198.9615696`，没有新增独立场景证据。  
证据：`C49/raw.json:2219–2228`。

**不能由此直接推出：**

- NLP 无界；
- reward/cost 符号写反；
- Bellman target 已被证明错误；
- v33 的失败全部由 heading 项造成。

目前只有 branch-state 函数检查，尚未取得用于比较的完整预测 terminal state 和同目标交叉评分。
