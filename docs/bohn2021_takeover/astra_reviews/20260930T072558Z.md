## 四、按影响排序的当前发现

### 1. 高：V35 的问题不只可能来自 heading；三个 state 方向都具有负二次曲率  
**关联：`A11`、`A6_strong_fixed_H_and_terminal_opportunity_not_closed`**

完整有符号系数现在提供了比上一轮更强的结构证据：

| V35 输入 | linear coefficient | quadratic coefficient |
|---|---:|---:|
| `theta` | −0.899227560 | −2.214164734 |
| `x` | −2.454081059 | −2.569124460 |
| `y` | +0.277894616 | −2.791463137 |

证据：`I33/terminal_coefficients.csv:7–9`。

作者 polynomial 是：

\[
V(s,g)=b+\sum_i a_i z_i+\sum_i q_i z_i^2,\qquad z=[s,g],
\]

没有交叉项。证据：

- `S/stable-baselines-horizon/stable_baselines/sac/policies.py:344–373`
- `S/gym-horizon/gym_let_mpc/utils.py:163–203`

实际 NLP 将 terminal **加到**最小化目标中，并乘正的 discount：  
`S/do-mpc-horizon/do_mpc/controller.py:1090–1112`。

**已验证的结构事实：**固定 goal 时，V35 的 state 部分是严格凹的 quadratic；它可能奖励可达集合中的某些极端 heading／绝对位置，而非单纯提供“靠近目标”的代价。

**尚未证明的因果结论：**这些项分别在 source242 救援、c13 质量恶化中贡献多少。下一 probe 必须同时分解 `theta`、`x`、`y` 项，不能预先把所有责任归给 heading。

另外，V15 的 `x/y` quadratic coefficient 也为负，只是量级较小；不能把 V15 直接当作已经校准正确的 value。证据：CSV `:2–4`。

#### context 缺失应如何解释

因没有 state–goal 交叉项：

\[
V(s,g)=V_s(s)+C(g),\qquad \nabla_sV=\nabla_sV_s.
\]

所以同 H、同 context 下，goal-only 项只是候选之间的共同常数，不能独自解释动作排序差异。它仍可能影响绝对 objective 数值及数值停止尺度，因此下一 probe 要保存完整参数并报告中心化分解。

当前 audit 的 observation slots 3/4 也**不是已恢复的真实 goal**：该 observation 是缩放后的 trajectory-relative quantity，见  
`experiments/bohn2021_reproduction/runtime.py:36–47`。本次已明确标为 heuristic，故不再将其误报为真实部署 context。

更一般地，当前 terminal 输入不含障碍／未来 reference 序列，且缺少 state–goal interaction。这是**表示能力限制**，不是已经证明的本批失败原因。
