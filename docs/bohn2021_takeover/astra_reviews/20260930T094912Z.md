   The current lead’s proposed H35 branch deserves a narrower interpretation. An H35-only tolerance failure would establish **horizon-dependent reconstruction error**, not uniquely a terminal-value cause.

   In the earlier lead report, the FD label’s index `3` was interpreted as a state component, and a gradient-norm product was treated as a predicted objective change. The inspected accessor instead identifies that index as the **collocation index**; the state variable is the later `x` or `y` token: [v34k accessor](/data/openai-agent/mobile-robot-mppi-study/experiments/bohn2021_aws/vehicle_true_variable_horizon_v34k_label_accessor_objective_localization_v0.py:245).    Moreover, these are derivatives of **the reconstructed objective**, not derivatives of the reconstruction error against the actual NLP objective. The latter was unavailable. Zero sensitivity of unused collocation entries is therefore compatible with the reconstruction’s own indexing; it does not localize an error.

   Neither
   \[
   \|\nabla J_{\rm recon}\|\,\|d\|
   \]
   nor constraint violation multiplied by an objective-gradient norm is an observed objective difference. A directional derivative requires the actual direction and consistent coordinates; converting constraint residual into state error additionally requires conditioning information. Likewise, `||lam_g||₁ × constraint_residual = 1.0033e-5` is a limited residual-scale calculation, not a general bound on disagreement between two objective evaluators. The quantities and unavailable direct evaluations are explicit in [v34m raw](/data/openai-agent/mobile-robot-mppi-study/research_artifacts/aws_diagnostics/vehicle_true_variable_horizon_v34m_residual_attribution_v0_20260930T111306Z/raw.json:259).

   For the same objective and exactly the same numerical input, solver non-convergence alone should not produce different objective evaluations. It matters here because infeasible iterates can separate formulas that happen to coincide at a feasible solution.

   **Competing explanations still include** state/index conventions, omitted nonzero terms, discount/scaling conventions, numerical evaluator differences, and inconsistent saved/evaluated inputs. Terminal-value error remains one hypothesis among them.
