# 概率基础说明：Stage 1

## 1. 当前估计不是一个“点”，而是一个 belief

在普通确定性 CV 中，预测器只输出：

```text
未来位置 = 一个点
```

Gaussian CV Kalman 输出：

```text
未来位置 = 均值 + 协方差
```

均值是当前最可信的预测；协方差描述估计可能偏离均值的方向和尺度。
它不是障碍物真实尺寸，也不是额外的物理障碍物。

对控制而言，可以把它理解为：

- state estimate：障碍物可能在哪里；
- covariance：我们对这个 state estimate 有多大把握。

## 2. 两种噪声必须分开

过程噪声进入真实动力学：

```text
真实障碍物并未严格按照匀速模型运动
```

它类似于控制中的 plant/model mismatch。

观测噪声只进入传感器：

```text
障碍物运动没有改变，但测量位置发生偏差
```

本阶段使用独立随机数流生成两种噪声。改变观测噪声不会改变真实轨迹，
因此可以判断性能变化到底来自运动随机性还是传感器误差。

## 3. Kalman filter 的两步

预测：

```text
上一时刻 belief + CV 动力学
→ 当前先验均值和协方差
```

校正：

```text
当前观测与预测的偏差
→ 按预测置信度和观测置信度融合
```

发生遮挡时没有校正步骤，系统只能依靠动力学向前推，所以协方差应逐步
扩大。这是一种正确行为：没有新信息时，不应该假装自己仍然同样确定。

## 4. 为什么“有协方差”还不够

如果模型声称某个 90% 概率区域能够覆盖真实位置，那么在大量独立样本中，
真实位置应大约有 90% 落在该区域内。这叫覆盖率校准。

本轮 smoke 的总体 90% 覆盖率约为 52.8%。分场景看：

- Noisy CV：约 93%--94%，接近声称概率；
- Speed/Direction/Combined Change：约 30%--48%，明显过度自信。

原因不是矩阵计算错误，而是单一 CV 模型无法表达突然转向、停止或反向。
模型认为自己仍然很确定，但真实障碍物已经换了运动规律。

因此：

```text
协方差合法（有限、对称、PSD）
≠
概率校准可信
```

这正是下一阶段需要 IMM 和 change detector 的原因。

## 5. 当前结论边界

当前只能说：

- 障碍物过程与观测生成正确且可复现；
- CV/Kalman 输出有限；
- Kalman 协方差在数值上合法；
- 基础工件和 seed 隔离正确；
- 单一 CV 在突变场景中明显低估不确定性。

当前不能说：

- Kalman 已经校准；
- 碰撞概率可信；
- 风险阈值可用于安全控制；
- IMM 或 Change-Aware IMM 有效；
- 动态避障性能已经改善。
