# Development amendments authorized by the user's follow-up

The user explicitly requested continued diagnosis and re-experimentation after
problems. No formal test had begun. Every amendment below was coded/committed
before its own measurements; earlier data and decisions remain unchanged.

1. Gate R v1 failed: all three physical candidates lacked the required increase
   over the nominal/default plant. Correction helped position but could worsen
   heading/aggregate error. No original reliable/unreliable label was retained.
2. Excitation revision tested low/high command envelopes and resting/rolling
   starts with the same six criteria. Its predeclared high/rolling primary still
   failed; L70 was substantially LOWER error than the physical default. This
   falsified the assumed ordering for that probe distribution, not the general
   reliability/foresight hypothesis.
3. Those results were designated calibration. We froze L70 as lower-error and
   physical default as higher-error and generated24 entirely new random probes
   with new initial states/commands. All six original H40 criteria passed:
   position .14378 -> .23132 -> .17609m; normalized state .34621 -> .56705 -> .40941.
   This is independent DEVELOPMENT validation of a relative error contrast,
   not exact model matching or formal test evidence.
4. Gate S v1 literally found mixed success (single obstacle:1/6). But Easy failed
   with physical goal distance1.06–1.24m while observed distance was ~.05m. Thus
   wheel odometry drift confounded the intended mechanism. The raw Gate S pass
   is preserved, but is not accepted as clean scene-mechanism evidence.
5. Sensor-isolated Gate S revision uses the EXISTING L70/pilot current pose/twist
   sensor mode for all arms. Same geometry, tolerance, cost, checkpoint, seed,
   candidates, actuator and budget settings. Current state can be observed;
   future truth is never an input. This isolates model dynamics and geometry.
   Any subsequent result applies to this observation assumption; odometry
   robustness becomes a separate later study, not a silently solved problem.

Primary thresholds were not relaxed. Calibration and validation banks are distinct.
Neither original Gate R was retrospectively relabelled passed. Development scenario
selection remains separate from any future formal test freeze. The later protocol
must reference the successful independent reliability and sensor-isolated scene
gates; it must not treat all preceding probes as unbiased formal replicates.
