# 实测延迟驱动的浅树策略搜索：预定实验协议

日期：2026-09-26，北京时间。登记前设计；机器登记完成后本文和源码固定。尚无本实验结果。车辆与倒立摆同时保留，目标不是仅让倒立摆规则诊断通过。

## 问题和方法偏离

旧有限门控方法完整验证四组任务×比较器均失败；失败状态诊断在已暴露倒立摆训练案例中发现手工C5降低实际延迟但没有提高成功数。由此提出新的、需要独立检验的假设：从完整闭环回报学习每步H分配，可以利用当前状态、允许的控制器预测及上一步求解状态，在不牺牲原任务成本与安全计数的前提下减少决策延迟。

这是改进方法：用分类交叉熵搜索学习深度2的决策树，不是作者SAC。原50步掩码NLP、原动力学与成本、H取值5/10/…/50、三种子独立固定H25/H30终端、有界相同NLP重试和规范reset保持不变。主策略不使用角度充分条件、规则教师、旧已选策略或旧训练标签初始化。C5只作为单独诊断比较器和附加消融；不能把规则的收益算作学习贡献。

## 学习器与部署

三内部节点、四叶子；节点学习特征和阈值，叶子学习H。每步重新选择，含第0步，不强制固定前五步。特征仅取当前状态、上一控制、至多50步控制器预测、剩余时间及上一初始/最终求解失败指示；第0步失败指示均为false。完整特征定义固定在 `latency_tree_policy.py`。特征不读真实未来、场景ID或随机种子。

连续阈值来自新搜索库固定基线轨迹的10/25/50/75/90分位数，包含失败状态；失败指示阈值固定0.5。初始节点选择均匀；每个叶子70%选择原固定H，其余30%均分其他9个H。每训练种子独立随机数。4代×12棵树；每代完整运行所有候选的全部12搜索案例，不剪枝、不删失败。选前3个按预定排名的精英，分类概率以0.6权重更新，再混入10%均匀探索。全部48候选及重复候选均计预算，固定参考每代重测一次用于时间漂移对照。

候选排名先比较约束违反项数，再比较 `相对原始总成本变化 + 0.5*(实测平均决策时间比−1)`，最后按候选ID。训练约束：每案例success不降、constraint不增；初始/最终失败步率不增；全案例物理+约束成本和总成本均不劣2%；每案例物理+约束成本不劣5%（算术容差1e-8）。不可行候选可指导搜索分布，不能成为最终候选。没有日志变换、裁剪回报、critic或不一致的续控标签。

每个种子从全部48候选中按完整搜索结果选最多4个合格树（相同参数去重）进入16案例训练内复选库。与固定参考、倒立摆纯C5比较器在两个完整串行随机顺序重复中运行。以同样安全与成本限制过滤，按两次时间比的平均和原始成本计算同一目标；固定参考始终包含，若无树合格就冻结固定回退并明确学习失败。C5不参与主学习策略选择。此复选库属于训练，不是正式验证。仅训练选择结果不能证明效果。

## 随机性、材料和时间测量

训练种子0/1/2；同任务不同种子的搜索和复选场景独立生成，每种子12+16案例。另每任务2个冒烟、64个验证、128个封存测试案例。评估场景在训练种子间配对，重复测量和控制步不当成新独立场景或训练种子。新输入与全部可解析已保存历史场景做精确去重；这不证明分布统计独立，也不覆盖未保存的历史训练。

场景种子：搜索2609261000+任务序号×100+训练种子；复选2609262000+任务序号×100+训练种子；冒烟2609260900+任务序号×100；验证2609263000+任务序号×100；测试2609264000+任务序号×100。搜索RNG为2609265000+任务序号×100+训练种子；复选/正式计时按冻结随机顺序，所有臂均测两遍。

搜索和复选串行运行，无其他实验Python并发。选择时间包含主方法所需的特征读取和树选择；控制时间包括全部初始/重试求解、可行性检查和内部预测记录。恢复日志开销独立测量并扣除，保留毛/净延迟、日志时间、reset和构造成本边界。仿真、外层审计上下文与轨迹写盘不在决策计时内。正式计时在完整控制评价和模型选择之后，对相同轨迹精确重放，独立于训练时间。宿主WSL调度仍是限制。

## 固定基线与贡献比较

1. 所有候选与固定臂均得到相同冻结终端和重试机会；自适应另有搜索预算，不能声称等预算优越。
2. 正式新验证上完整搜索独立训练seed0的H5/10/…/50；以不降低success、不增加constraint及初始/最终失败步率的候选中最低原始成本提名。H25/H30原主参考始终纳入。提名后若seed1/2该H终端缺失，按原设置各独立训练15k步，不挪用自适应终端。
3. 共用自适应终端也完整评价10个固定H×全部三种子，以全部三种子满足同一安全规则的候选中最低跨种子平均原始成本选共同H。独立基线与共用终端基线分别比较，不合并不同终端。
4. 倒立摆额外报告纯C5及冻结学习+C5，三个种子与两次计时均完整。主学习策略须独立达标，组合方法不能代替主方法；若组合优于固定仅来自C5而主方法不达标，按学习失败处理。

不同独立终端均采用既有共用主终端H50 reset适配器，计分前恢复自身终端；逐案例检查计分初始状态/上一控制完全一致。所有真实约束、求解失败和提前终止保留。

## 正式验收和封存

两任务×两固定比较器×全部三种子：success不降、constraint不增、初始/最终失败率不增，物理+约束成本不劣2%，实际回合内H改变。每任务要求共同一条路线：全部种子总成本改善至少3%且配对95%成本差上界<0；或全部种子实际平均决策延迟改善至少10%、配对95%时间比上界<1、两个重复均更快、总成本不劣2%。用10,000次配对场景bootstrap，训练种子一起保留并逐种子报告，区间条件化于已训练模型；不把三种子当成大种子总体。

新64案例验证仅用于上述固定基线选择与完整效果准入，不调学习树参数或checkpoint。只有主学习方法全部门槛通过，冻结策略、比较器与审计后才登记并执行128案例独立确认；相同门槛再过一次才能宣称成功。失败则测试保持封存。本轮不得读取或重用旧失败实验的测试结果。

## 执行、审计和预算

先登记全部源码/配置/继承模型和实验规则，再生成新划分、做去重审计；冒烟覆盖两任务全部三种子，每种子两个新场景、固定参考与一棵预定非学习测试树，两次精确重放。冒烟树仅验证节点/动作执行，不参与候选选取。合成检查覆盖零成本、失败率分母、负成本、树路由和CE概率。正式训练须等冒烟的记录/成本/因果特征/独立积分/计数审计通过。

所有step/reset尝试及求解尝试/完成在调用前后持久化；每步原始状态/动作/成本/时域/策略特征/恢复/时间追加记录，完整回合再写汇总。候选失败不覆盖、不默默重启；已有完成只核验后复用。不使用默认的旧报告器重写历史交付。

训练上界（不含验证/测试和未来所需固定补训）：搜索6作业×(1次阈值参考+4代×13臂)×12案例=3,816回合；复选最多倒立摆3×6臂×16案例×2遍+车辆3×5臂×16案例×2遍=1,056回合；冒烟48回合。以车辆150步、倒立摆100步的较粗统一上界为738,000控制步；生成银行另有556次reset及热身，构造器未仪表化调用单列未知，不补为零。每代实际步数、reset、求解/重试和CPU墙时均记录，失败和重复候选均计入。模型参数与训练内选择、所有完整候选数据及预算冻结后才进入验证。

本协议的模型与候选容量是有界搜索，不能保证最优，也可能拟合计时噪声或训练案例。保留全部负结果；任何科学规则更改必须新登记、新划分，不能回写本协议。

## 方法依据的范围

Szita与Lőrincz（2006），Learning Tetris Using the Noisy Cross-Entropy Method，Neural Computation 18:2936–2941，DOI 10.1162/neco.2006.18.12.2936，提供带探索扰动的交叉熵策略搜索先例；本文没有复用其Tetris策略或超参数。Vos与Verwer（2024），Optimizing Interpretable Decision Tree Policies for Reinforcement Learning，arXiv:2408.11632，提供直接优化完整决策树的先例，其DTPO使用策略梯度，与本方案的分类交叉熵搜索不同。上述文献仅支持方法类别具有先例，不能证明本MPC设置、特征、预算或验收将有效。
