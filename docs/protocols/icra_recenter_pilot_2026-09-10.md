Candidate weighted_recenter: first run the existing frozen surrogate on 100 candidates, compute provisional weights from task costs only (the proposal importance correction is not yet available at this point), average predicted states using those weights with circular heading averaging, batch residual descriptors at these 36 anchors, then rerun the same 100 candidates and recompute task costs. Uniform_recenter repeats the same work with uniform provisional weights, isolating weighting from extra computation. This is a heuristic, not an unbiased importance estimator or a guaranteed error bound.
