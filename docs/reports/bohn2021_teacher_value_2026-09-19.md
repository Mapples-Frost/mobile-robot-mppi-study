# 倒立摆教师数据训练：奖励、价值校准与新场景结果

实验于 2026-09-18 启动，2026-09-19 完成。本轮用可核验的同状态分支成本训练 H 价值网络，再补充学生实际到达的状态。补充训练版三个种子在 12 个新场景上的平均平移成本为 **115.6258**，低于验证选出的固定 H24 的 **149.3188**，也低于 H5/H30 规则的 **119.1474**。分别降低 **22.56%** 和 **2.96%**；全部 108 个保留评估回合零约束终止、零求解失败。

这是监督训练的时域价值策略，没有执行 SAC 更新，没有求得全局最优控制路径。新场景、特征和学习目标与旧 SAC 不同，因此不能把改善单独归因于“旧训练数据错误”。

## Reward 定义

继续沿用原有物理权重，只移除直立平衡点的势能常数。记控制后状态的位置误差为 e，速度 v，摆角 theta，角速度 omega，控制力 u，正常物理阶段成本为：

```text
L = 10*e^2 + 0.4*v^2 + 0.05*v*omega*cos(theta)
    + (1/120)*omega^2 + 0.4905*(1-cos(theta)) + 0.1*u^2
reward = -(L + 0.003*H + failure_penalty) / 0.6
failure_penalty = (10 + 0.4905) * remaining_steps  # 仅在物理约束终止时
gamma = 0.97
```

10×剩余步是原失败罚项；额外 0.4905×剩余步仅补齐势能零点变换，不引入新的物理失败权重。对任何完整或提前失败回合：

```text
-0.6 * sum(reward) = 原始总成本 + 600*0.4905
```

因此此次奖励零点调整保持未折扣回合成本的排序。没有奖励裁剪、模仿教师动作的额外奖励或仅鼓励缩短 H 的奖励。物理失败和 600 步有限回合末端都不自举；教师分支中途截断才使用近似尾项。

折扣标签与未折扣整回合成本是不同口径，均保存并报告。0.97 的折扣对远期参考变化权重很低，不能把整回合未折扣改善自动称为折扣目标改善。

## 数据、教师与训练

- 全新场景：8 个原始训练场景（种子 26091840）、4 个标签验证场景（26091841）、4 个学生补充训练场景（26091842）、12 个最终保留场景（26091843）。旧保留集不参与训练。
- 每回合 600 步、两次预告移位。参考位置的三个幅度独立抽取 0.35–0.85 米并交替方向，变化时刻随机；初始扰动比前一轮筛查更大。动力学、约束、终端和 H 罚项共用。
- 每个场景安排 12 个锚点，覆盖初始恢复、平稳、参考变化前、移位及恢复。每点比较 H∈{5,10,20,25,30,40,50}。状态、MPC 内部求解状态、时钟和 RNG 通过进程 fork 精确复制；原状态首步与重复分支验证精确一致。
- 先执行一个候选 H，然后使用同一个冻结 H5/H30 规则继续，共续跑 60 步。超出锚点可见 50 步预告的参考保持最后一个可见值，避免特权未来信息。尾项是局部 Riccati 物理值及有限剩余步的 H5 计算值；物理尾项本身是局部无限时域近似，不是精确有限时域最优值。
- 标签是相对 H30 的折扣成本差。网络拟合去掉已知首步 H 罚项差后的残差，行动时再加回该精确项。选择预测成本最低的 H；没有另外的随机 actor。
- 网络 19 输入、64×64 ReLU、7 输出，H30 相对值约束为零。输入仅包括当前状态、剩余时间和可见参考预告的派生特征，不输入完整事件日程。
- 种子 0、1、2 各训练 3,000 次 Adam 更新（3e-4、batch64），SmoothL1 加 0.1 加权排序损失，只用最终检查点。原始 96 个训练状态后，预先指定初版种子 0 收集 48 个新学生状态；全部种子从相同的各自初始化重训 144 个状态。两轮六个模型均保留，不按测试选种子。

48 个验证状态只评估，不参与梯度。采样按阶段覆盖而不是按时间均匀堆积；全部分支均保存，也明确没有观察到失败分支。因此本轮不能证明已覆盖近失稳或大扰动工况。

## 保留场景结果

成本越低越好。表中物理/总成本均消除平衡点势能常数；没有失败时总成本等于物理成本与 H 成本之和。百分比明确依赖这个零点，不用负原始成本计算百分比。

|方法|平移总成本|物理成本|H 成本|平均 H|约束失败|
|---|---:|---:|---:|---:|---:|
|固定 H24|149.3188|106.1188|43.2000|24.00|0/12|
|固定 H30|153.5724|99.5724|54.0000|30.00|0/12|
|H5/H30 规则|119.1474|99.5724|19.5750|10.88|0/12|
|初版监督模型，三种子均值|116.2829|103.1549|13.1279|7.29|0/36|
|补充学生状态后，三种子均值|115.6258|102.9117|12.7142|7.06|0/36|

|训练种子|初版成本|补充训练成本|补充版胜固定 H24 场景数|补充版胜规则场景数|
|---|---:|---:|---:|---:|
|0|116.6934|116.6054|12/12|12/12|
|1|118.5673|116.9131|12/12|12/12|
|2|113.5879|113.3590|12/12|12/12|

固定 H 在四个验证场景上重新粗扫并细扫，共 19 个候选，选出 H24。它是最佳已测固定值，不是全局最优证明。H24/H25 验证成本相差仅 0.0193，未通过弱化固定基线制造大差距。

相对固定 H24，补充版平均节省总成本 33.6929，其中物理成本 3.2071、H 成本 30.4858。相对规则，总成本节省 3.5216，但物理成本增加 3.3392、H 成本减少 6.8608。因此不是控制质量全面提升，主要是更积极且有效的时域缩短。

跟踪 RMSE：固定 H24 为 0.09974 米，规则为 0.10029 米，补充版均值 0.10084 米。物理成本含能量和控制力，不能将其与单独位置 RMSE 等同。

补充数据相对初版的未折扣平均改善只有 0.565%，幅度有限。初版三个种子的折扣成本为 2.57447、2.56462、2.55803，补充版为 2.58651、2.57027、2.56237，均略变差；不能宣称补充训练改善了所有目标。

## Critic 校准

在未参与训练的 48 个验证状态上，补充版三个种子的平均动作 regret 为 0.004748、0.002878、0.003453（reward 缩放后的折扣成本单位），选择落在教师最佳值 0.02 以内的比例为 85.4%、93.8%、91.7%。这些是相对所定义的近似教师标签，不是全局最优 Q 误差。

补充数据改善了两个种子的验证排序，但种子 0 的 regret 从 0.003701 增至 0.004748。完整验证回合也有类似差异：种子 0 的未折扣成本略变差，另两个改善。报告保留全部模型，未按保留表现挑最佳种子。

## 预算和审计

- 教师标签共 192 个状态、1,344 条分支、80,640 步，其中验证标签也计入计算预算；正式训练使用 144 个状态×7 个动作标签。
- 16 个采集前缀回合共 9,600 步；完整验证和保留评估共 212 回合、127,200 步（104 验证、108 保留）。
- 正式保存轨迹共 217,440 步；额外 fork 重复检查 60 步和原状态首步 1 步；重置预热 229 步。总物理模拟预算 **217,730 步**。预检查首批七条分支复用，未重复计数。
- 六个模型各 3,000 次监督更新；没有 SAC 更新。额外仿真远多于标签数量，不能宣称低成本等预算胜过旧 SAC。
- 独立核对每条保存转移的物理奖励、约束、输入范围、预告边界、实际动作、分支折扣与尾项、模型导出、相同种子两轮初始化、固定 H 选择和场景完整性；全部通过。
- 三个作者源码仓库干净，登记源码和场景哈希一致；没有后台训练或评估遗留。

## 结论范围

这轮证明：在此长平稳段与预告移位任务族中，近似教师成本监督可以训练出优于最佳已测固定 H 和已有简单切换规则的策略。它没有证明旧数据存在错误，也没有隔离数据质量、特征和算法变化的各自贡献；没有获得全局最优路径，没有复现原论文场景，没有证明实际 CPU 加速。

后续若继续，优先增加教师尾部长度敏感性、临界/偏离状态覆盖及与同观测同奖励 SAC 的对照。当前 12 个保留场景已经观察过，不能再作为下一轮调参的最终测试集。
