# 候选轨迹误差与控制权重误差：可检验的机制

本文是当前实验的数学解释与待检验假设，不宣称新定理或已证明的闭环优势。所有关系首先针对同一状态、同一候选控制集合和同一重要性修正，不能直接推导整个闭环轨迹的优劣。

设完整模型与近似模型给第k个候选的总成本分别为J_k与Jhat_k，delta_k=J_k-Jhat_k，温度为lambda>0。两种权重为

    what_k = exp(-Jhat_k/lambda) / sum_j exp(-Jhat_j/lambda)
    w_k = what_k exp(-delta_k/lambda) / sum_j what_j exp(-delta_j/lambda).

共同的成本偏移不会改变权重；重要的是候选间成本误差的差异。仅有一个不带成本权重的轨迹位置RMSE，不能确定这些delta_k，尤其不能确定它们与候选控制的相关性。

对小误差在delta=0处作一阶展开，加权控制均值的差为

    ubar - ubar_hat
      = -(1/lambda) sum_k what_k (u_k - ubar_hat) delta_k + O(||delta||^2).

因此与控制方向相关的成本误差，即使平均预测位置误差较小，也可能改变转向均值。反之，所有候选近似同样偏移的成本误差可以很大，却不改变权重。这是softmax及加权均值的直接性质，并非本工作的原创理论。

还可给出无需小误差假设的保守界。令Delta=max(delta)-min(delta)，TV=(1/2)sum_k|w_k-what_k|。由上式的权重比落在[exp(-Delta/lambda),exp(Delta/lambda)]内，有

    TV <= min(1, (exp(Delta/lambda)-1)/2).

若某个控制分量的候选范围为[u_min,u_max]，则

    |ubar_j-ubar_hat_j| <= (u_max-u_min) TV.

后一式由正、负权重差总量都为TV且总权重差为0直接得到。此界可能非常松，只约束固定候选集合下的加权控制分量；不是动力学误差上界、碰撞安全保证或最终闭环性能保证。共同的逐分量限幅不会扩大该分量差，但实际终端覆盖、下一时刻状态及未来采样分布仍须单独检查。

## 已有实测与解释边界

30次标准质量实际MuJoCo重跑中，每5个周期对相同的实际候选集合同时计算完整与近似成本。所有重跑状态与原轨迹差小于1e-9；不施加反事实动作，也不增加随机数采样。额外完整计算的时间不能用于基准速度比较。

原方向入口、弯道、出口的平均权重TV分别为0.00706、0.01105、0.01802；加权角速度均值绝对差分别为0.00165、0.00318、0.00520rad/s。出口的不带权重预测位置误差仅0.443mm，低于入口0.945mm和弯道1.000mm。这说明位置RMSE与控制敏感性在本次诊断中并不同步。

这些是周期描述量，不是独立样本，也不是“误差已经造成闭环退化”的因果证明。诊断种子曾用于确认后的定位，不能再算修正方案的未见测试集。

## 当前干预与反证条件

使用第一遍近似候选的临时任务成本权重，重新定位第二遍残差近似参考轨迹。假设：把近似参考位置放在较可能影响控制的轨迹区域，可以降低相关成本偏差。使用均匀权重执行完全相同的第二遍计算作为消融，对比纯额外计算的作用。

临时权重尚未包含重要性修正，最终MPPI权重仍包含；因此这是启发式候选。第二遍计算可能吃掉计算收益，也可能因错误的临时权重而恶化精度。新开发种子实验保留上述失败可能；预先规定不值得扩展时保留原候选，不通过选择方向或质量更换算法来制造优势。
