frozen Chapter 1 configuration resolves to `planner.optimizer:
paper_rl_driven`. Its measured Gaussian population is generated by
`PaperRLDrivenMppiController._gaussian_samples`, which still used a direct
i.i.d. `rng.normal` call. The original A/B driver would therefore have written
different arm labels and resolved `noise_basis` values without changing the
actual measured Gaussian candidates.

  existing per-step standard deviation afterward.
